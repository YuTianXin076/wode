| 文件 | 内容 |
|---|---|
| 太极拳文献汇报_20页.pdf | 20 页 PDF，可直接阅读 |

| 太极拳文献汇报_HTML_20页.zip | HTML 离线版、20 个独立页面、原图和备注 |
| 01_论文题目与汇报切入点.svg | 单独的第 1 页 SVG |

## 在 Mac 下载

1. 登录有权访问此私有仓库的 GitHub 账号。
2. 打开所需文件。PDF、SVG 可使用文件页面的 Download raw file（下载原始文件）按钮；ZIP 可点击 View raw 或下载按钮。
3. 也可以返回仓库首页，选择 Code → Download ZIP，下载完整仓库后解压。
4. 在 Finder 中打开桌面，新建“太极拳文献汇报”文件夹，将下载的文件移入。

SVG 插入 PowerPoint 前，建议安装 SVG ZIP 中的配套字体。各版本 PowerPoint 转换为形状后的文本编辑性可能不同。

文件大小及 SHA-256 校验值见 文件信息.json 与 SHA256SUMS.txt。
